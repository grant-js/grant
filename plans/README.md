# Active story plans

Store durable story briefs and stack plans here while work is in flight:

- `YYYY-MM-DD-<slug>-brief.md` — from `docs/contributing/templates/story-brief.md`
- `YYYY-MM-DD-<slug>-stack.md` — from `docs/contributing/templates/stack-plan.md`

See [Agentic SDLC](../docs/contributing/agentic-sdlc.md). Cursor-local drafts may also live under `.cursor/plans/` (gitignored); prefer this directory for plans shared across Cursor, Claude, Codex, and humans.
