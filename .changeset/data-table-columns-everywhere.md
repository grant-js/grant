Every table now resizes and starts at a width that fits its content. The Field / Value tables on the detail pages (and the user General card, which no longer has its own copy), the notification preference tables and the feature comparison in the email verification dialog use the shared data table: resizable data columns with saved widths per user and table, fixed-width switch and check columns, and an empty last column that takes the spare space. Tables without a column picker (project apps, signing keys, webhook deliveries) now get resize handles too.
