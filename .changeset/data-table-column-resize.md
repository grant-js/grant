Resize data table columns: drag the handle on a header's right edge, or focus it and use the arrow keys (Shift for bigger steps, Home/End for the limits, Enter or double-click to reset). Widths are remembered per user and table, and "Reset columns" restores the default widths. Columns start as wide as their longest content (up to their declared width), data cells have consistent horizontal padding, and spare room in a narrow table goes to an empty trailing column instead of stretching the real ones.
